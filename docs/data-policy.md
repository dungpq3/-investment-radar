# Data policy

This repository is public.

Allowed here:
- public Binance market data and derived deterministic features;
- scanner health/state/history;
- non-personal configuration and code.

Do **not** commit:
- Binance API keys or secrets;
- Telegram bot token;
- account balances, portfolio NAV, holdings, screenshots, transaction history;
- personally identifying financial snapshots.

Telegram credentials belong only in GitHub Actions Secrets.
Personal portfolio/gold/account snapshots should use a separate private repository before being persisted to Git.
